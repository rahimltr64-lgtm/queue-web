# طابور الحلاق — النسخة الويب

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً وارفع كل محتويات هذا المجلد في الجذر.
2. Settings ← Pages ← Source: Deploy from a branch ← main / root.
3. بعد دقيقة يصبح الموقع على: https://USERNAME.github.io/REPO/
4. افتح https://USERNAME.github.io/REPO/qr.html ← يولّد الملصق تلقائياً بالرابط الصحيح ← اطبعه أو احفظ الصورة.

## ملاحظات
- الموقع والتطبيق يقرآن ويكتبان في نفس المسار `shops/BARBER01/queue` في Firebase، فالطابور واحد.
- لمحل آخر استخدم الرابط: `https://.../?shop=CODE` وولّد له QR من qr.html?u=الرابط.
